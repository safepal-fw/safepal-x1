# SafePal X1 Firmware

This article shows all of the upgrade changelogs of the X1 hardware wallet firmware.

---

## SafePal X1 V1.0.34b (hotfix)

📆 Released Date: 2026/8/5

- **Security fix (arbitrary signing):** Fixed an issue where the device could display incorrect transaction information during signing. Under certain conditions, the information shown on the device screen did not match the transaction actually being signed, which could result in loss of funds if the transaction was approved based on the incorrect display.
- All users are strongly advised to update.
